# Q2 – Information Gathering Using Browser Extensions

## Target

`example.com`

## Objective

The objective of this project was to perform passive information gathering
against `example.com` using publicly available security and technology
intelligence tools.

## Tools Used

- Wappalyzer
- Netcraft Site Report
- Shodan

## 1. Wappalyzer

Wappalyzer was used to identify technologies associated with the target website.

### Evidence

![Wappalyzer](./evidence/01-wappalyzer-example-com.png)

### Key Observations

- Nuxt.js
- TypeScript
- PHP
- Tailwind CSS
- Vue.js
- React
- Angular
- Apache HTTP Server
- Cloudflare
- Google Sign-In
- reCAPTCHA
- Google Analytics
- HTTP/2 and HTTP/3
- TLS 1.3

---

## 2. Netcraft

Netcraft Site Report was used to collect publicly available information about
the target's network, hosting, DNS/security information and site technologies.

### Evidence

![Netcraft](./evidence/02-netcraft-example-com.png)

### Key Observations

- Cloudflare was visible in the network information.
- IPv4 and IPv6 information was displayed.
- DNS-related information was available.
- SPF and DMARC information was displayed.
- Site technology information was provided.
- HTTP acceleration and web technology information was visible.

---

## 3. Shodan

Shodan was used to review publicly indexed information associated with the
searched domain and related infrastructure.

### Evidence

![Shodan](./evidence/03-shodan-example-com.png)

### Key Observations

The Shodan report displayed information related to:

- Ports
- Organizations
- Products
- Operating systems
- Web technologies
- Protocol versions
- SSL/TLS versions
- JA3 fingerprints
- JARM fingerprints

The report also displayed technologies such as Nginx, Apache HTTP Server,
Amazon Web Services and Amazon CloudFront.

---

## 4. Comparison

| Tool | Primary Purpose |
|---|---|
| Wappalyzer | Website technology identification |
| Netcraft | Network, hosting and site technology information |
| Shodan | Publicly indexed infrastructure information |

Each tool provided a different perspective on the publicly observable
environment of the target.

---

## 5. Security Relevance

The information collected through passive reconnaissance can help a security
professional understand the externally visible technology environment of a
target.

Technology, hosting, DNS, services and protocol information can be useful
during an authorized security assessment when determining areas that may
require further investigation.

The presence of a technology or service does not by itself indicate a
vulnerability.

---

## 6. Conclusion

This project demonstrated passive information gathering using Wappalyzer,
Netcraft and Shodan.

The exercise showed how multiple reconnaissance tools can be used together to
develop an initial understanding of a target's publicly observable
technologies and infrastructure.

No exploitation or intrusive testing was performed.
